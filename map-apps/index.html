Mapping apps

Four plain JavaScript starters with the same OpenStreetMap basemap and sample stations.

  • MapLibre GL JS
  • Mapbox GL JS Public access token required
  • OpenLayers
  • Leaflet

Each app supports panning, zooming, station popups, a layer toggle, and resetting the view.

Use the performance panel to compare point and layer workloads, repeat a fixed camera path, and export timing results.

Station temperatures are synthetic examples, not weather observations.
